# FORMA Premium — как получать деньги

## 1. Оплата переводом на Kaspi — работает уже сейчас
Деньги приходят **напрямую на карту Kaspi** (твою или родителя). Никаких договоров не нужно.

**Включить (один раз):** войти в FORMA своим аккаунтом → Профиль → «Пользователи» → блок «Оплаты Premium» → «Реквизиты»:
- включить «Принимать оплату переводом»;
- номер телефона Kaspi, на который будут приходить деньги, и имя получателя (как его видно в Kaspi, например «Айгуль Ж.»);
- цены (по умолчанию 1 290 ₸ / месяц, 7 990 ₸ / год).

**Как платит покупатель:** Premium → выбирает месяц или год → переводит сумму на Kaspi с кодом в комментарии (например, F12345) → жмёт «Я оплатил».

**Что делаешь ты:** при входе в FORMA появится уведомление «Новые оплаты на проверку». Открываешь «Пользователи», находишь в Kaspi перевод с этим кодом → «Пришло». Premium включается покупателю сам. Если перевода нет → «Нет».

Там же видно, сколько всего получено.

Важно: если продажи станут регулярными, по закону РК это доход от бизнеса. Родителю лучше открыть ИП (бесплатно через eGov или приложение банка) и платить налог по упрощёнке. С ИП можно подключить и автоматическую оплату картой (Kaspi Pay, CloudPayments, ioka) — тогда подтверждать вручную не нужно.

## 2. Приложение для Android — работает уже сейчас
- Ссылка на скачивание: https://github.com/anvarzangardauletuly-netizen/forma-app/releases/download/android-latest/FORMA.apk
- На сайте FORMA на Android-телефоне сверху появляется кнопка «Скачать приложение», и есть карточка «Приложение FORMA» в Профиле.
- APK собирается сам при каждом обновлении сайта (GitHub Actions → Android).

Сейчас APK подписывается временным ключом: чтобы обновиться, старую версию надо удалить и поставить новую (данные в аккаунте сохраняются). Чтобы обновления ставились поверх и чтобы выложить в Google Play, нужен постоянный ключ подписи в секретах GitHub (см. п. 3).

## 3. Google Play (Android) — нужен аккаунт
1. Родитель регистрирует аккаунт разработчика: play.google.com/console, разово $25, нужен паспорт (18+).
2. Ключ подписи: создать файл ключа (.jks) в Android Studio (Build → Generate Signed Bundle → Create new). В репозитории GitHub → Settings → Secrets and variables → Actions добавить:
   `ANDROID_KEYSTORE_B64` (файл .jks в base64), `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS`.
   После этого каждая сборка даёт ещё и файл AAB для Google Play (Actions → запуск → Artifacts), а APK обновляется поверх старого.
3. В Play Console: создать приложение FORMA, загрузить AAB, заполнить описание (готовый текст — `store/listing.md`), политику конфиденциальности (https://forma-app-green-beta.vercel.app/privacy.html), анкету о данных.
4. Для новых личных аккаунтов Google требует закрытое тестирование: 12 тестировщиков в течение 14 дней (друзья, одноклассники) — потом можно публиковать.

Внутри Google Play оплата Premium должна идти через Google Play (оплата переводом в версии из магазина скрывается автоматически, когда подключены покупки).

## 4. App Store (iPhone) — нужен аккаунт
1. Apple Developer Program — $99 в год, регистрирует родитель (18+), нужен Mac для сборки или облачная сборка.
2. Пока iPhone-пользователи ставят FORMA с сайта: Safari → «Поделиться» → «На экран „Домой“».

## 5. Покупки в магазинах через RevenueCat (когда будут аккаунты)
Код уже в приложении (`js/premium.js`, плагин RevenueCat). Нужно:
1. В App Store Connect / Play Console создать подписки `forma_premium_month` и `forma_premium_year`.
2. revenuecat.com → проект FORMA → подключить магазины → Entitlement `premium` → Offering `default` с пакетами «месяц» и «год».
3. Публичные ключи (`appl_…`, `goog_…`) вписать в `BILLING` в `js/premium.js`.
4. Секретный ключ RevenueCat → Supabase → Edge Functions → Secrets → `REVENUECAT_SECRET`.

Магазины берут 15% (программа для малого бизнеса), остальное приходит на банковский счёт владельца аккаунта раз в месяц.
