# Как выложить FORMA в Google Play — по шагам

Всё, что можно сделать без аккаунта, уже готово: приложение, иконка, баннер, скриншоты, тексты, политика конфиденциальности, оферта.
Файлы для загрузки — в папке `store/play/`.

## Шаг 1. Аккаунт разработчика (делает родитель, 18+)
1. Открыть **play.google.com/console** → войти в Google-аккаунт родителя (лучше создать отдельный, например forma.dev@gmail.com).
2. Тип аккаунта: **«Личный» (Personal)**.
3. Оплатить **$25** один раз картой (Kaspi Gold подходит — это Visa).
4. Пройти проверку личности: фото удостоверения/паспорта, адрес, телефон. Обычно 1–3 дня.
5. Указать «Контактные данные для пользователей»: e-mail и (по желанию) сайт `https://forma-app-green-beta.vercel.app`.

## Шаг 2. Ключ подписи (один раз, вместе со мной)
Google Play принимает только файл **AAB**, подписанный ключом загрузки.
1. Напиши мне «сделай ключ для Google Play» — я создам ключ и дам тебе **файл** (не в чат, а файлом) с инструкцией.
2. Ты добавляешь его в GitHub: репозиторий **forma-app → Settings → Secrets and variables → Actions → New repository secret**:
   - `ANDROID_KEYSTORE_B64` — содержимое файла;
   - `ANDROID_KEYSTORE_PASSWORD` — пароль из файла;
   - `ANDROID_KEY_ALIAS` — `forma`.
3. После этого каждая сборка (вкладка **Actions → Android → последний запуск → Artifacts**) даёт файл **FORMA-google-play-aab** — его и загружаешь в Play.
   Бонус: APK с сайта тоже начнёт обновляться поверх старой версии.

Ключ никому не показывай и никуда не выкладывай. Google хранит свою копию ключа приложения (Play App Signing), так что если ключ загрузки потеряется — его можно сбросить через поддержку Google.

## Шаг 3. Создать приложение в Play Console
**Все приложения → Создать приложение:**
- Название: `FORMA — калории и КБЖУ`
- Язык по умолчанию: Русский
- Тип: **Приложение**, **Бесплатное** (покупки внутри — Premium)
- Отметить согласия с правилами.

## Шаг 4. Страница в магазине (Рост → Основная страница)
- **Краткое описание (80 знаков):** `Считайте калории и КБЖУ: 36 000 продуктов, сканер штрихкодов, шаги и вес`
- **Полное описание:** из `store/listing.md` → раздел «Полное описание».
- **Значок 512×512:** `store/play/icon-512.png`
- **Баннер 1024×500:** `store/play/feature-graphic-1024x500.png`
- **Скриншоты телефона:** `store/play/screenshot-1…6.png` (минимум 2, загружай все 6).
- Категория: **Здоровье и фитнес**. Теги: «Подсчёт калорий», «Питание».
- E-mail для связи — тот же, что в шаге 1.

## Шаг 5. Анкеты «Содержание приложения» (Политика → Содержание приложения)
Отвечать так:
| Раздел | Ответ |
|---|---|
| Политика конфиденциальности | `https://forma-app-green-beta.vercel.app/privacy.html` |
| Доступ к приложению | «Часть функций требует входа» → указать тестовый аккаунт (создай отдельный e-mail и пароль для проверяющих Google) |
| Реклама | Нет рекламы |
| Возрастной рейтинг (анкета IARC) | Категория «Справочные, новости, образование и др. / Утилиты»; насилия, азартных игр, общения пользователей нет → получится 3+ |
| Целевая аудитория | **13 лет и старше** (не отмечать младше 13 — иначе особые правила для детей) |
| Новостное приложение | Нет |
| Приложение для здоровья | Да: «Фитнес и активность», «Питание» |
| **Health Connect** | Указать разрешение `READ_STEPS`. Объяснение: «Показываем количество шагов за день в дневнике и учитываем их в расходе калорий. Ничего не записываем, не передаём третьим лицам и не используем для рекламы». |
| Безопасность данных (Data safety) | Собираются: e-mail и имя (аккаунт), здоровье и фитнес (питание, вес, шаги), фото — только обрабатываются, не хранятся. Шифруются при передаче: да. Пользователь может удалить данные: да (в приложении «Профиль → Удалить все мои данные» + по e-mail). Передача третьим лицам: нет. |
| Финансовые функции | Нет |
| Госприложение | Нет |

## Шаг 6. Закрытое тестирование — обязательно для новых личных аккаунтов
Google требует: **минимум 12 тестировщиков, которые 14 дней подряд держат приложение установленным**.
1. **Тестирование → Закрытое тестирование → Создать трек** → загрузить AAB (шаг 2).
2. Тестировщики: список e-mail (Gmail) — одноклассники, друзья, семья, 15–20 человек с запасом.
3. Отправить им ссылку «Присоединиться к тестированию» (появится в консоли). Каждый: открывает ссылку → «Стать тестировщиком» → устанавливает из Play.
4. Просить не удалять 14 дней и иногда открывать.
5. Через 14 дней: **Главная → «Подать заявку на доступ к рабочей версии»** → ответить на вопросы (как тестировали, что исправили).

## Шаг 7. Рабочая версия
**Рабочая версия → Создать выпуск** → тот же AAB → страны: Казахстан (и другие по желанию) → «Отправить на проверку». Проверка обычно 1–7 дней.

## Шаг 8. Оплата Premium внутри Google Play
По правилам Google подписки в приложении из Play оплачиваются **только через Google Play** (карты, в т.ч. Kaspi Gold, привязываются в Google Play). Деньги Google перечисляет раз в месяц на банковский счёт, минус 15%.
1. **Настройка → Платёжный профиль** — создать (данные родителя, банковский счёт в KZT/USD). Проверь, что Казахстан есть в списке стран продавца.
2. **Монетизация → Подписки → Создать:** `forma_premium_month` (1 290 ₸, период 1 месяц) и `forma_premium_year` (7 990 ₸, 1 год). Можно добавить «бесплатный пробный период 7 дней».
3. Зарегистрироваться на **revenuecat.com** (бесплатно) → проект FORMA → приложение Android `kz.forma.app` → подключить Google Play (по их инструкции: сервисный аккаунт Google Cloud). Создать Entitlement `premium`, Offering `default` с пакетами месяц/год.
4. Мне: публичный ключ RevenueCat для Android (`goog_…`) — его можно написать в чат. Секретный ключ RevenueCat вставляешь сам: **Supabase → Edge Functions → Secrets → `REVENUECAT_SECRET`**.
5. Я вписываю ключ, собираю новую версию — в приложении появятся кнопки «Месяц / Год» с ценой из Google Play, автопродление и отмена — средствами Google.

## Что остаётся за тобой — коротко
1. Аккаунт Play Console на родителя ($25, проверка личности).
2. Написать мне «сделай ключ» → добавить 3 секрета в GitHub.
3. Скачать AAB из Actions, создать приложение, заполнить страницу и анкеты (ответы выше).
4. Найти 12+ тестировщиков на 14 дней.
5. Платёжный профиль + подписки + RevenueCat → прислать мне `goog_…`.
